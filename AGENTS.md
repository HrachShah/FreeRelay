# FreeRelay - Team Roster

## Roles and Responsibilities

- **agent-lead**: Team management, task planning, delegation, and monitoring.
- **agent-engineer**: Full-stack engineer. Backend API development (FastAPI), routing logic, and dashboard integration.
- **agent-designer**: Frontend engineer. React/Next.js specialist, dashboard UI/UX, data visualizations.
- **agent-auth-expert**: Identity management. Supabase Auth, multi-tenancy, and security.
- **agent-analytics-expert**: Data visualization. Recharts, SWR, and analytics API integration.
- **agent-routing-expert**: Routing algorithms and LLM provider optimization.
- **agent-qa-specialist**: Quality Assurance and Documentation. CLAUDE.md, AGENTS.md, integration testing.
- **agent-devops-expert**: Deployment pipelines and infrastructure.
- **agent-documentation-expert**: Technical writing and API documentation.
- **agent-security-expert**: API security and multi-tenant isolation.

## Team Principles
- **Glass Box Transparency**: Always show Actual vs Baseline LLM costs.
- **Speed to ROI**: Focus on features that deliver measurable savings quickly.
- **Self-Serve**: The platform must be usable without manual onboarding.
